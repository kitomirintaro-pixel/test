概要

静的な HTML と CSS だけで構成されています。ホスティング（GitHub Pages、Netlify など）にそのまま置けるシンプルな構成です。

特徴

  • 読みやすいタイポ

    Noto Sans JP と DM Sans の組み合わせで、日本語と欧文のバランスを整えています。

  • レスポンシブ

    スマートフォンからデスクトップまで、画面幅に合わせてレイアウトが変わります。

  • アクセシビリティ

    スキップリンクや適切な見出し階層で、キーボードや読み上げにも配慮しています。

連絡・次のステップ

index.html の文言を差し替え、styles.css の CSS 変数でテーマカラーを変えてみてください。

ローカルで確認するには、ターミナルでこのフォルダに移動して npx serve . や python3 -m http.server を実行すると便利です。
