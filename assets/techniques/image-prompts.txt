SpinCoach 技術イラスト — ChatGPT 用プロンプト一覧（全13枚）
================================================================

【共通スタイル（毎回先頭に付ける）】
卓球の練習イラスト。520x244px、横長。
暗い背景（#152032）、シンプルなフラットデザイン。
赤いラケット、オレンジのボール。
オレンジの太い矢印＝ボールの軌道、水色の矢印＝ラケットの振り方。
文字・ラベル・日本語は入れない。アイコン風にわかりやすく。
下に緑の卓球台の端が少し見える。

【保存先】assets/techniques/ フォルダ
WebP または PNG（PNG でも自動認識）

----------------------------------------------------------------
1. drive.webp / drive.png — ドライブ
----------------------------------------------------------------
【動き】ラケットでボールを前へまっすぐ押し出す。水平のオレンジ矢印

----------------------------------------------------------------
2. speed.webp / speed.png — スピードドライブ
----------------------------------------------------------------
【動き】速い水平ドライブ。太い前向き矢印と、上下に並行の短い速度線

----------------------------------------------------------------
3. loop.webp / loop.png — ループドライブ
----------------------------------------------------------------
【動き】ボールが上に弧を描いて相手コートへ。紫色の曲線矢印

----------------------------------------------------------------
4. curve.webp / curve.png — カーブドライブ
----------------------------------------------------------------
【動き】ボールが横に曲がる。横へ膨らむ曲線矢印

----------------------------------------------------------------
5. shoot.webp / shoot.png — シュートドライブ
----------------------------------------------------------------
【動き】低い打点でネット際をまっすぐ押す。低い位置の水平矢印

----------------------------------------------------------------
6. backhand.webp / backhand.png — バックドライブ
----------------------------------------------------------------
【動き】バックハンドで左方向へ打つ。左向きのオレンジ矢印

----------------------------------------------------------------
7. smash.webp / smash.png — スマッシュ
----------------------------------------------------------------
【動き】高い位置のボールを上から叩く。下向きの太い矢印

----------------------------------------------------------------
8. serve.webp / serve.png — サーブ
----------------------------------------------------------------
【動き】ボールを上に投げ（点線矢印）、ラケットで打って相手側へ飛ばす

----------------------------------------------------------------
9. attack.webp / attack.png — 攻め・第3球
----------------------------------------------------------------
【動き】積極的に前へ攻める速いドライブ。強い前向き矢印

----------------------------------------------------------------
10. flick.webp / flick.png — フリック
----------------------------------------------------------------
【動き】台に近い短い球をラケットで上に弾く。低い位置から上への矢印

----------------------------------------------------------------
11. defense.webp / defense.png — 守備・ブロック
----------------------------------------------------------------
【動き】左から来たボールをラケット面で受け、右へ短く返す。左→右の矢印

----------------------------------------------------------------
12. footwork.webp / footwork.png — フットワーク
----------------------------------------------------------------
【動き】打った後、足元の踏み出しと中央へ戻る矢印（点線で戻る動き）

----------------------------------------------------------------
13. mental.webp / mental.png — メンタル
----------------------------------------------------------------
【動き】集中・落ち着き。中央の選手シルエットに、周囲から内向きの矢印

================================================================
【課題チェックボックスとの対応】
同じ画像を複数の課題で共有します（13枚で全課題をカバー）。

drive        → ドライブ、ナックル、攻めプッシュ など
speed        → スピードドライブ、カウンター、フリック系 など
loop         → ループ、上回転ラリー、ロビング など
serve        → サーブ全般（上回転・下回転・ロング等）
defense      → カット、ブロック、レシーブ、回転見極め
footwork     → フットワーク、球速適応
mental       → メンタル
（その他はファイル名と1対1）

画像を置いたらブラウザをリロードするだけで反映されます。
